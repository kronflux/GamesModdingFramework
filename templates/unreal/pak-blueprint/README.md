# {{name}}

A pak/Blueprint mod scaffold generated by GMF.

1. Create or copy the content into an Unreal project that matches the game's engine version.
2. Cook the assets for the game's target platform.
3. Package the cooked content with repak (`repak pack <cooked> <name>.pak`) or the UnrealPak that ships with the matching Unreal Engine.
4. Deploy with `unreal.deploy --input type=pak`; the pak and its `.ucas`/`.utoc` sidecars go to `Content/Paks/LogicMods`.
5. Start the game and confirm the assets load; read the UE4SS log for package mount errors.

The scaffold contains no game content and no cooked assets.
