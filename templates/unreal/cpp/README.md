# {{name}}

A UE4SS C++ mod scaffold generated by GMF.

1. Install the UE4SS SDK and set `UE4SS_INCLUDE` and `UE4SS_LIB` (the library folder holding `UE4SS.lib`).
2. Build with `xmake build` (or run `unreal.build`). The project builds as C++23 for x64 with the dynamic MSVC runtime (`/MD`), the same settings UE4SS uses.
3. Deploy with `unreal.deploy --input type=cpp`; the DLL goes to `<UE4SS>/Mods/{{name}}/dlls/main.dll`.
4. Start the game once and read the UE4SS log for load errors.

The source exports `start_mod` and `uninstall_mod`, which UE4SS looks up by name, and logs through `RC::Output::send` from `<DynamicOutput/DynamicOutput.hpp>`.

The scaffold does not bundle UE4SS headers or binaries.
